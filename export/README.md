## Which file to use

| File | What it is | Use it for |
| --- | --- | --- |
| `<subject>.md` | Must-read list, every topic with every question that asked it (word for word, newest first), unmapped questions, then every paper in full | Reading and revising, printing |
| `questions.csv` | One row per question: paper, part, number, marks, wording, topics | Excel / Google Sheets, importing into another site |
| `questions.json` | The same rows as JSON, topics resolved to name, chapter and tier | Importing into another site or app |
| `topics.csv` | One row per topic: chapter, tier, times asked, years, every sitting, questions and marks on the transcribed papers | Building a checklist |
| `sittings.csv` | One row per sitting the frequency analysis recorded against a topic | Year-wise views, the reconstructed sittings |
| `all-data.json` | `topics.json`, `papers.json` and `scored.json` verbatim, in one file | Running a copy of this site — split it back into `data/` |

## Reading the data honestly

- **18 of the 105 papers are undated.** Papers print a code and series; `year` is filled only where one is legibly written or printed on the paper, and `year_note` says which. Otherwise it is blank.
- **Marks are the paper's own**, so a few are fractional — 9-mark questions split 4.5 + 4.5.
- **Some papers are incomplete** — the photograph hid part of them. The `paper_incomplete` column says what is missing.
- **Unmapped questions** have no topic on the checklist. Mostly MCQ blocks, plus real gaps such as beta blockers and adrenaline, whose Pharmacology chapter (ANS) has no topics.
- **Two counts per topic, kept apart.** `times_asked` is the frequency analysis; `on_paper_questions` counts the transcribed papers. They come from different sets of sittings and are not reconciled.
- **Combined papers.** Older Pathology and Microbiology sittings share one sheet; a few of their questions are tagged with a topic from the other half. The subject files list those under the topic's own subject and say which paper they came off.
- **Paper codes are this university's.** If another syllabus uses different codes or chapters, map by topic name rather than by id.
